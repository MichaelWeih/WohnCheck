# Vermieter-Logos

Diese Logos dienen ausschließlich der Identifikation der jeweiligen Wohnungsgesellschaften.

Quellen:

- `vonovia.svg`: Wikimedia Commons, `File:Vonovia Logo.svg`, als `PD-textlogo` markiert, mit Trademark-Hinweis.
- `dogewo21.svg`: Wikimedia Commons, `File:DOGEWO21 logo.svg`, als `PD-textlogo` markiert, mit Trademark-Hinweis.
- `leg-immobilien.svg`: Wikimedia Commons, `File:LEG Immobilien Logo 2021.svg`, als `PD-textlogo` markiert, mit Trademark-Hinweis.

Wichtig: `PD-textlogo` betrifft die urheberrechtliche Einordnung einfacher Wort-/Formmarken. Markenrechte bleiben davon unberührt. Die Logos dürfen in WohnCheck nur zur neutralen Identifikation verwendet werden, ohne eine Partnerschaft, Empfehlung oder Freigabe durch die Markeninhaber zu suggerieren.
